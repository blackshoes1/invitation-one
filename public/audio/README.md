# 배경음악 (BGM) — FD-5

이 폴더에 음원 파일을 넣고 환경변수로 경로를 지정하면 청첩장 좌상단에 **재생/일시정지 토글**이 나타납니다.

## 사용법

1. 이 폴더(`public/audio/`)에 음원 파일을 넣습니다. 예) `bgm.mp3`
2. `.env.local` 에 경로를 지정합니다.

   ```
   NEXT_PUBLIC_BGM_URL=/audio/bgm.mp3
   NEXT_PUBLIC_BGM_TITLE=우리의 노래   # (선택) 버튼 라벨/툴팁
   ```

3. 값이 비어 있으면 토글 버튼은 표시되지 않습니다. 음원 로드에 실패해도 자동으로 숨겨집니다.

## 동작

- 브라우저 자동재생 정책상 **첫 재생은 하객이 버튼을 탭**해야 시작됩니다.
- 한 번 켜면 `localStorage` 에 기억되어, 다음 방문 시 첫 상호작용(탭/스크롤)에서 이어서 재생됩니다.
- 볼륨은 40%, 반복 재생.

## ⚠️ 저작권

배포 전, 사용 허락된(라이선스 구매 또는 직접 제작) 음원인지 반드시 확인하세요.
상업 음원의 무단 사용은 저작권 침해가 될 수 있습니다.
