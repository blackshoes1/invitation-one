# 도트 마당 '정원 예식장' 설계

작성일: 2026-10-06 · 상태: 사용자 승인(설계안·진행 방식) → 문서 검토 대기
선행 문서: `2026-10-06-guestbook-village-topdown-design.md` (바람의 나라식 탑뷰), `2026-10-06-guestbook-pixel-village-design.md` (메이플식 옆면)

## 이 문서의 위치

탑뷰 마당의 **배경·세계 크기·걷는 영역**을 사진 배경에서 **코드로 그린 정원 예식장**으로 바꾸고,
신랑·신부 캐릭터, 갤러리 이동, 하객 자동 말풍선, 글씨 선명화를 더한다. 아래 항목은 이 문서가 대체하고,
나머지(4방향 걷기, 앞·뒤·옆 스프라이트, 가장자리 입장, 터치·말풍선·절전·접근성·에러 처리)는
탑뷰 설계 문서를 그대로 따른다.

| 탑뷰 설계 문서 항목 | 이 문서에서 |
|---|---|
| 예식장 사진을 도트로 변환한 배경(192×128) | 코드로 그린 정원 예식장 배경(192×176) |
| 걷는 영역 `y ∈ [62, 128]` | `y ∈ [72, 176]` (세계 크기 192×176) |
| 하객만 등장 | 단상 위 신랑·신부 고정 캐릭터 추가 |
| 말풍선은 누를 때만 | 하객 자동 말풍선 추가(약 6초마다) |
| 이름표·말풍선 글씨를 도트 배율로 그림 | 화면 해상도로 그림(또렷하게) |
| 원본 사진 변환·사람 지우기 | 불필요(사진을 쓰지 않는다) |

## 목표

참고 이미지(정원에서 아치 아래 신랑·신부가 서 있고 하객들이 이름표를 달고 모이는 탑뷰 마당)와 같은 구성으로,
글을 남긴 하객이 위에서 내려다본 정원 예식장을 걸어 다니고, 신랑·신부를 누르면 갤러리로 이동한다.
참고 이미지의 그림·이름은 쓰지 않는다(저작권·개인정보) — 구성만 참고해 새로 그린다.

## 범위

- **포함**: 정원 배경(코드로 그린 PNG), 세계 크기 192×176, 신랑·신부 고정 캐릭터와 안내 말풍선, 갤러리 이동,
  하객 자동 말풍선, 이름표·말풍선 글씨 선명화, 에셋 교체 지점 정리.
- **제외**: 고해상도 에셋 도입(사용자가 구하는 동안 나중에 교체), 장애물·충돌, 원근 크기 보정,
  DB·API 변경, 새 npm 의존성, 참고 이미지 사용.

## 배경(정원)

- 산출물: `public/pic/village-bg.png` (192×176 PNG, 수십 KB). 스크립트로 그린다 — 시드 고정이라 같은 입력이면 항상 같은 그림이다.
  스크립트는 저장소에 넣지 않는다(일회성, 결과 PNG 의 해시를 구현 계획에 기록한다).
- 위에서 본 구성:
  - 모서리의 큰 나무 수관(왼쪽 위·오른쪽 위, 위쪽 가장자리에 작은 것 둘).
  - 가운데 위에 단상(모래색 바닥) + 계단 3단, 그 위에 꽃 아치(위쪽 반원 꽃 띠, 양쪽 기둥, 흰 커튼).
  - 단상 양옆에 나무 화단(꽃 상자) 둘.
  - 단상에서 아래로 이어지는 모래색 포장길(`x ∈ [84, 107]`), 양옆에 분홍·흰 꽃길.
  - 왼쪽에 라벤더, 오른쪽에 꽃덤불 셋, 잔디 얼룩·풀 포기·들꽃.
- 걷는 영역(발 위치 기준): `x ∈ [8, 184]`, `y ∈ [72, 176]`. 위쪽(단상·화단·나무)은 장식이고 장애물·충돌은 없다.
- 이미지를 불러오지 못하면 단색 잔디 배경으로 대신 그린다(마을은 깨지지 않는다).

## 신랑·신부

- 단상 위 고정 위치(발 위치): 신랑 `(86, 56)`, 신부 `(106, 56)`. 앞모습으로 서 있고 움직이지 않는다(`fixed`).
- 이름표는 설정(`@/lib/wedding` 의 `groom.name`, `bride.name`)을 쓴다. 신랑은 금색, 신부는 분홍색 이름표.
- 외형: 신랑은 검은 정장(옷 `#2f3340`, 바지 `#1e1f26`), 신부는 흰 드레스(옷·바지 `#f6f3ee`)에 머리 꽃. 머리색은 둘 다 짙은 갈색.
  바지 색을 지정하려고 `Look` 에 선택 필드 `pants` 를 추가한다(없으면 기존 `#3d4a63`).
- 누르면 말풍선(제목은 그 사람 이름, 본문 `저를 누르면 사진들 볼 수 있어요!`)이 뜬다.
  **같은 캐릭터의 말풍선이 떠 있을 때 다시 누르면** 갤러리 섹션(`#gallery`)으로 스크롤한다
  (`behavior: "smooth"`, `prefers-reduced-motion` 이면 `"auto"`). `#gallery` 가 없으면 아무 일도 하지 않는다.
- 이를 위해 `src/components/sections/Gallery.tsx` 의 최상위 `<section>` 에 `id="gallery"` 를 추가한다(그 밖의 변경 없음).
- 신랑·신부는 하객 수·메시지 탭·`mineId` 와 무관하다(`items` 에 없다).

## 하객 자동 말풍선

- 마을이 보이는 동안(루프가 도는 동안) 약 6초마다, 말풍선이 열려 있지 않으면, 메시지가 있는 하객 중 무작위 한 명의 말풍선을 4초간 띄운다.
  그 하객은 말풍선을 보는 동안 멈춘다(누른 경우와 같다).
- 루프 안(`dt` 누적)에서 센다 — 화면 밖·백그라운드 탭에서는 멈추고, `prefers-reduced-motion` 에서는 자동으로 뜨지 않는다.
- 사용자가 누른 말풍선이 있으면 자동 말풍선은 뜨지 않고, 누르면 자동 말풍선은 즉시 대체된다.

## 글씨 선명화

- 이름표와 말풍선 글씨를 도트 배율이 아니라 **화면 해상도(약 11 css px)** 로 그린다. 위치는 논리 좌표 × 배율이다.
  스프라이트와 배경은 그대로 도트로 유지한다.
- 말풍선 최대 폭·3줄 말줄임·4초 닫힘 규칙은 그대로이고, 폭은 css px 기준으로 맞춘다.

## 에셋 교체 지점 (나중에 고화질 에셋을 구했을 때)

구현은 지금의 코드 도트로 하되, 그림이 들어가는 곳을 두 군데로 모아 둔다.
1. **배경**: `public/pic/village-bg.png` 한 장. 같은 비율(12:11)의 PNG 로 바꾸고 `WORLD_W/H`, `AREA`, 신랑·신부 위치만 새 그림에 맞게 고친다.
2. **캐릭터**: `pixelSprite.ts` 의 `bakeSprites(look)` 가 `Record<FrameName, 그릴 수 있는 이미지>` 를 돌려주는 구조다.
   시트 PNG 로 바꿀 때는 이 함수의 내부와 `SPRITE_W/H` 만 바꾼다. `villageSim.ts` 는 캐릭터 크기를 `HALF_W`, `BOX_H` 상수로만 알고,
   `pixelSprite.ts` 의 타입(`FrameName`)만 import 하므로 로직은 손대지 않는다.
이번 작업에서는 시트 로더를 만들지 않는다(필요해질 때).

## 테스트

- 이동·고정: 하객은 영역(`y ∈ [72, 176]`) 안에 머무름, 대각선 없음, 입장 후 영역 도달; 신랑·신부(`fixed`)는 `dt`·`timer` 와 무관하게 위치·방향이 변하지 않음.
- 스프라이트: `pants` 지정 시 바지 칸이 그 색, 미지정이면 기존 색; 모든 프레임 규격 유지.
- 배경: PNG 가 192×176 이고 100KB 미만.
- 화면(샘플 데이터 임시 페이지, 저장소에 넣지 않음): 정원 배경 선명도, 신랑·신부 이름표·말풍선, 두 번째 누름에서 갤러리로 스크롤,
  자동 말풍선(약 6초 간격, 누르면 대체, 화면 밖 정지), 글씨 선명도, 배경 로드 실패 대체 화면, 모션 줄이기에서 자동 말풍선 없음.
  실제 방명록 탭과 `#gallery` 는 Supabase·실제 페이지가 필요해 배포 미리보기에서 확인한다.
