# 방명록 '도트 마을' 설계

작성일: 2026-10-06 · 상태: 사용자 승인(접근안 A, 동작 설계) → 문서 검토 대기

> **일부 대체됨**: 마을의 배경·이동·캐릭터 방향·입장 방식은 `2026-10-06-guestbook-village-topdown-design.md`
> (바람의 나라식 탑뷰 마당)가 대체한다. 데이터·터치·말풍선·절전·접근성·에러 처리는 이 문서를 그대로 따른다.

## 목표

방명록(`Guestbook.tsx`)에 `🏘️ 마을` 탭을 추가한다. 글을 남긴 하객 1명이 도트 캐릭터 1명이 되어
메이플스토리 마을처럼 발판 위를 걷고 점프한다. 캐릭터를 누르면 그 하객의 축하 메시지가 말풍선으로 뜬다.

## 범위

- **포함**: 마을 탭, 도트 캐릭터 생성(코드), 이동 로직, 말풍선, 새 하객 낙하 등장, 절전 처리.
- **제외**: 하객의 직접 조작, DB·API 변경, 외부 이미지 파일, 메이플스토리 원본 이미지 사용(저작권).

## 접근 방식

Canvas 2D 한 장에 모든 캐릭터를 `requestAnimationFrame`으로 그린다.
`imageSmoothingEnabled = false`로 도트를 선명하게 유지한다. 하객이 100명이어도 가볍게 돈다.
캐릭터 터치 판정은 캔버스 좌표로 직접 계산한다. 접근성은 기존 메시지 탭이 대신한다.

## 데이터

- 새 쿼리나 RPC는 없다. `Guestbook.tsx`가 이미 불러온 `celebrations`를 그대로 쓴다.
- 표시 대상은 `buildFeed(celebrations)` 결과와 같다(마음배송 또는 별점 있는 직접배달).
  말풍선에 보여 줄 메시지가 있는 하객만 마을에 나온다.
- 사용 필드는 공개 필드만이다: `id`, `name`(이미 마스킹된 공개 이름), `kind`, `message`, `review`.
  관리자 전용 `realNames`는 마을에 쓰지 않는다.
- `mineId`가 있으면 내 캐릭터의 이름표를 금색으로 강조한다.

## 구성 요소 (파일 3개 + 수정 1개)

| 파일 | 역할 | 의존 |
|---|---|---|
| `src/lib/pixelSprite.ts` | 16×24 도트 프레임 데이터(정지·걷기·점프), `id` 해시로 머리색·옷색·모자 결정, 프레임을 오프스크린 캔버스에 미리 그리기 | 없음(순수) |
| `src/lib/villageSim.ts` | 캐릭터 상태 머신(정지 / 걷기 / 점프 / 낙하), 발판 충돌, 방향 전환. `step(state, dt, rng)` 순수 함수 | 없음(순수) |
| `src/components/sections/PixelVillage.tsx` | 캔버스 렌더, 터치 판정, 말풍선, IntersectionObserver·visibility 처리 | 위 둘, `Celebration` 타입 |
| `src/components/sections/Guestbook.tsx` | `ViewMode`에 `"village"` 추가, `ToggleBtn` 하나 추가, 마을 탭 렌더 | `PixelVillage` |

## 마을 구성

- 논리 해상도 192×128(2배 확대 표시, 모바일 폭 약 384px 기준). 풀밭 바닥 1단과 발판 2단.
- 배경(하늘, 구름, 풀밭, 발판)은 코드로 그린 도트이다.
- 캐릭터 스프라이트 데이터는 `pixelSprite.ts` 한 곳에 모아 두어, 나중에 시트 PNG로 바꿔도
  `villageSim.ts`는 수정하지 않는다.

## 캐릭터 동작

- 상태: `idle` → `walk`(좌/우) → 가끔 `jump`를 무작위로 반복한다(시간은 난수로 분산해 동기화 방지).
- 발판 끝에서는 방향을 바꾼다. 위·아래 발판이 가까우면 점프나 낙하로 이동한다.
- 발밑에 별명 이름표를 그린다. 내 캐릭터는 금색이다.
- 새 하객이 폴링으로 들어오면 하늘에서 떨어져 등장한다. 기존 토스트와 함께 보인다.

## 상호작용

- 캐릭터 터치 시 말풍선에 `name`과 메시지(`message` 또는 `review`)를 보여 주고, 해당 캐릭터는 잠시 멈춘다.
- 다른 곳을 누르거나 4초가 지나면 말풍선을 닫는다. 겹친 캐릭터는 위에 그려진 쪽이 우선한다.
- 메시지가 긴 경우 말풍선 안에서 줄바꿈하고 최대 3줄로 자른다(말줄임). 전문은 메시지 탭에서 본다.

## 절전·접근성·에러 처리

- 마을 탭이 비활성이거나 캔버스가 화면 밖(IntersectionObserver)이면 루프를 멈춘다.
- `document.hidden`이면 멈춘다. `dt`는 상한(예: 50ms)을 두어 복귀 시 순간이동을 막는다.
- `prefers-reduced-motion`이 켜져 있으면 가만히 서 있는 정지 화면만 그린다(터치·말풍선은 동작).
- 캔버스 컨텍스트 생성 실패 시 안내 문구(`마을을 불러오지 못했어요`)를 보여 준다. 메시지 탭은 영향 없다.
- 캔버스에는 `role="img"`와 요약 `aria-label`(예: `축하해 주신 N명의 도트 마을`)을 둔다.
- 하객 수가 0이면 기존 `empty` 상태를 따른다(마을 탭 자체가 안 보임).

## 테스트

- `tests/unit/pixelSprite.test.ts`: 같은 `id`는 항상 같은 색 조합, 모든 프레임이 16×24 크기, 색 인덱스 범위 검사.
- `tests/unit/villageSim.test.ts`: 발판 위에 머무름, 끝에서 방향 전환, 낙하 후 착지, 동일 시드면 동일 결과.
- 렌더·터치는 브라우저 미리보기로 수동 확인한다(탭 전환, 터치 말풍선, 모바일 폭, 백그라운드 정지).
- 기존 e2e는 마을 탭을 건드리지 않으므로 회귀 확인만 한다.

## 열린 결정 (구현 계획에서 확정)

- 발판 높이와 배치의 구체 좌표, 캐릭터 크기 미세 조정은 미리보기에서 보며 정한다.
- 표시 인원의 상한은 두지 않는다(총 자리 100). 성능이 문제면 최신 N명으로 제한한다.
- 이 저장소는 Next.js 16이다. 구현 전에 `node_modules/next/dist/docs/`에서 클라이언트 컴포넌트·
  `"use client"` 관련 변경점을 확인한다(`AGENTS.md` 지침).
