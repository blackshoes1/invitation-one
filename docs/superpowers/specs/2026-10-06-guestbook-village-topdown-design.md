## 이 문서의 위치

선행 문서의 마을을 **바람의 나라식 탑뷰 마당**으로 교체한다. 아래 항목은 이 문서가 대체하고,
나머지(데이터, 터치·말풍선, 절전, 접근성, 에러 처리, 파일 경계)는 선행 문서를 그대로 따른다.

| 선행 문서 항목 | 이 문서에서 |
|---|---|
| 하늘·구름·풀 바닥·발판 2~3단 | 도트 변환한 사진 배경 한 장 |
| 중력·발판·점프·낙하 이동 | 상·하·좌·우 4방향 걷기 (점프 없음) |
| 옆모습 프레임(정지·걷기·점프) | 앞·뒤·옆 프레임(정지·걷기) |
| 새 하객이 하늘에서 낙하 | 새 하객이 아래쪽 가장자리에서 걸어 들어옴 |
| "외부 이미지 파일 없음" | 배경 PNG 한 장은 `public/` 에 둔다 (캐릭터는 여전히 코드 생성) |

## 목표

글을 남긴 하객 1명 = 도트 캐릭터 1명이, 예식장 사진 위를 바람의 나라처럼 앞뒤좌우로 걸어 다닌다.
캐릭터를 누르면 그 하객의 축하 메시지가 말풍선으로 뜬다.

## 범위

- **포함**: 사진 배경(도트 변환), 4방향 이동, 앞·뒤·옆 스프라이트, 가장자리 입장, 기존 터치·말풍선 유지.
- **제외**: 장애물·충돌, 캐릭터끼리 충돌, 원근에 따른 크기 보정, 하객의 직접 조작,
  DB·API 변경, 새 npm 의존성, 원본 사진 파일의 저장소 반입, 게임 원본 이미지 사용(저작권).

## 마당(배경)

- 입력: 사용자가 준 예식장 사진(세로 1125×1500). 아래쪽 3:2 영역(세로 750px, 천막·통로·의자·잔디)을 자른다.
- 변환: 192×128 로 줄이고(단계적 축소), 색을 줄여 도트 느낌을 낸다. 색을 줄이며 어두워지는 것은 밝기 보정으로 푼다.
- 사람 제거: 사진 속 사람(왼쪽 파란 재킷, 가운데 허리 숙인 사람, 천막 뒤 스태프)은 주변 색으로 덮어 지운다.
  **변환 결과는 저장소에 넣기 전에 사용자에게 보여 확인받는다.**
- 산출물: `public/pic/village-bg.png` (192×128, 수십 KB). 원본 사진과 변환 스크립트는 저장소에 넣지 않는다
  (원본은 개인정보·용량 문제, 스크립트는 일회성).
- 걷는 영역: 울타리 아래 전체. 발 위치 기준 `x ∈ [8, 184]`, `y ∈ [62, 128]`. 장애물 없음.
- 그리는 순서: 아래쪽(y 가 큰) 캐릭터가 위쪽 캐릭터를 가린다.
- 로드: `Image` 로 불러오고, 로드 전이거나 실패하면 단색 잔디 배경으로 대신 그린다(마을은 깨지지 않는다).
  배경은 같은 출처 파일이라 CSP `img-src 'self'` 에 걸리지 않는다.

## 캐릭터

- 크기 16×24 유지. 머리색·옷색·모자는 하객 `id` 로 정하는 기존 규칙 유지.
- 방향 3종: **앞**(아래로 걸을 때), **뒤**(위로 걸을 때), **옆**(오른쪽). 왼쪽은 옆모습을 좌우 반전해 쓴다.
- 프레임: 방향마다 정지 1 + 걷기 2. 점프 프레임은 제거한다.
  - 앞: 눈 두 개. 뒤: 얼굴 없이 머리카락만. 옆: 눈 하나와 옆얼굴.
  - 모자는 방향마다 알맞게 보이도록 패치를 방향별로 둔다(야구모자 챙은 앞·옆에만 보임).
- `FrameName` 은 `"down_idle" | "down_walk1" | "down_walk2" | "up_…" | "side_…"` 형태로 바꾼다.
  걷기 애니메이션은 기존처럼 `walk1 → idle → walk2 → idle` 을 초당 6프레임으로 돈다.

## 이동

- 상태: `idle` ↔ `walk`. 방향 `dir ∈ {down, up, left, right}`.
- `walk` 는 한 방향으로 0.6~2.0초 걷는다(속도 24px/s). `idle` 은 0.5~2.0초 선다. 시간·방향은 난수로 분산한다.
- **대각선 이동 없음**: 한 프레임에 x 와 y 가 동시에 바뀌지 않는다.
- 걷는 영역 끝에 닿으면 위치를 영역 안으로 되돌리고, 막힌 방향을 제외한 다른 방향을 고른다.
- 말풍선을 보는 캐릭터는 그 자리에 멈춘다(`frozen`).
- 순수 함수 `stepWalker(w, dt, rng, frozen)` 가 새 객체를 돌려주는 구조는 유지한다.
- **입장**: 처음 목록의 하객은 영역 안 임의 위치에서 시작한다. 이후 폴링으로 들어온 하객은
  화면 아래 가장자리 바깥(발이 화면 밖)에서 위쪽으로 걸어 들어와 영역에 닿으면 일반 상태로 전환한다.
  입장 중에는 영역 하한 클램프를 적용하지 않고, 말풍선을 보는 중(`frozen`)이어도 영역에 닿을 때까지 계속 걷는다
  (선행 구현의 "공중이면 착지까지 계속 낙하"와 같은 규칙). 모션 줄이기에서는 입장 없이 바로 영역 안에 선다.

## 상호작용·절전·접근성·에러 처리

선행 문서와 같다: 터치 → 이름+메시지 말풍선(3줄 말줄임, 4초 또는 캔버스의 빈 곳을 누르면 닫힘),
내 캐릭터(`mineId`) 이름표는 금색, 화면 밖·`document.hidden` 에서 루프 정지, `dt` 상한 50ms,
`prefers-reduced-motion` 에서 정지 화면(터치·말풍선은 동작), 컨텍스트 실패 시 `마을을 불러오지 못했어요`,
`role="img"` + `축하해 주신 N명의 도트 마을` 로 시작하는 `aria-label`.
선행 구현의 리뷰 반영(컨텍스트 실패 격리, 모션 줄이기 말풍선 타이머)은 유지한다.

## 테스트

- 이동: 항상 영역 안에 머무름, 한 번에 한 축만 변함(대각선 금지), 영역 끝에서 방향 전환,
  `frozen` 시 정지, 입장 후 영역 안에 도달, 같은 시드면 같은 결과, 입력 객체 불변.
- 스프라이트: 모든 방향·프레임이 16×24 이고 허용 글자만 사용, 앞·뒤·옆이 서로 다름,
  같은 `id` 는 같은 외형, 모자 패치가 방향마다 유효한 칸만 덮음.
- 화면: 샘플 데이터 임시 페이지(저장소에 넣지 않음)로 모바일 폭에서 배경 선명도, 4방향 걷기, 말풍선,
  화면 밖 정지, 이미지 로드 실패 시 대체 배경을 확인한다. 실제 방명록 탭은 Supabase 가 필요해 배포 미리보기에서 확인한다.
