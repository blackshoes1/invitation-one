# 하객 문자(SMS) 운영 — 솔라피

작성: 2026-09-09 · 예식 2026-10-18

관리자 알림(신랑신부에게 가는 텔레그램)은 `docs/NOTIFICATIONS.md` 를 본다.
이 문서는 **하객에게 나가는 문자**다.

## 언제 나가는가

| 동작 | 문자 |
|---|---|
| 주문 **확정** | ✅ 감사·일정 안내 (`site_settings.confirm_sms` 로 문구 수정 가능) |
| 주문 **취소** | ❌ 안 보낸다 |
| 주문 **완료** | ❌ 안 보낸다 |
| **일정 변경** | 관리자가 `문자 안내` 체크박스로 매번 선택 |
| '내 신청 찾기' 복구 링크 | 복구 요청 시 |

2026-09-09 에 취소·완료(리뷰요청)를 뺐다. 취소 안내는 사정을 설명해야 하는
연락인데 자동 문자는 "취소되었습니다"만 남기고 끝나 하객을 더 당황하게 하고,
리뷰요청은 청첩장을 받은 하객에게 후기를 조르는 문자라서다.

## ⚠️ 솔라피 IP 접근 제한을 **켜지 말 것**

이게 이 문서에서 제일 중요하다.

솔라피 콘솔에는 "허용 IP" 설정이 있다. **켜면 문자가 통째로 멈춘다.**

```
Solapi 403: {"errorCode":"Forbidden",
             "errorMessage":"허용되지 않은 IP(13.112.47.96)로 접근하고 있습니다."}
```

**Vercel 은 고정 아웃바운드 IP 를 주지 않는다.** 서버리스 함수가 나갈 때 쓰는
IP 는 요청마다·배포마다 바뀐다. 그래서 그때 찍힌 IP 를 허용 목록에 넣어도
다음번엔 다른 IP 로 나가 또 막힌다. **개별 IP 등록으로는 안정적으로 못 쓴다.**

보안이 약해지는 것 아니냐 — API Key + Secret 으로 HMAC 서명을 해서 보내고 그
키는 서버(Vercel 환경변수)에만 있다. IP 제한은 그 위에 얹는 보조 장치인데,
**고정 IP 가 없는 환경에서는 보조가 아니라 차단기**다.

> 예식 당일에 이게 켜져 있으면 확정 문자가 한 통도 안 나간다.
> 보안 설정을 정리할 일이 있어도 이 항목만은 건드리지 말 것.

## 환경변수

| 이름 | 비고 |
|---|---|
| `SOLAPI_API_KEY` | **정확히 16자** (`NCS…`) |
| `SOLAPI_API_SECRET` | |
| `SOLAPI_SENDER` | 솔라피에 **사전 등록된** 발신번호 |

셋 중 하나라도 없으면 발송을 건너뛴다(`skipped`) — 로컬·미설정 배포용이고
실패가 아니다. 어드민에는 "솔라피 키 미설정으로 미발송"으로 뜬다.

### 붙여넣기 사고

대시보드에 값을 붙여넣을 때 줄바꿈·공백이 함께 들어가는 일이 잦다. 그러면
솔라피가 통째로 거절한다:

```
Solapi 400: {"errorCode":"ValidationError",
             "errorMessage":"child \"apiKey\" fails because [\"apiKey\" length must be 16"}
```

`src/lib/sms.ts` 가 세 값을 모두 `.trim()` 하므로 앞뒤 공백은 이제 알아서
걷힌다. 그래도 길이가 16이 아니면 **솔라피를 호출하지 않고** 바로 실패시키고
몇 자인지 알려준다 — 하객 수만큼 400 을 맞아 봐야 원인만 가려진다.
키 값 자체는 로그·응답 어디에도 남기지 않는다(길이만).

## 실패는 반드시 화면에 뜬다

예전에는 한 건도 못 보냈는데 **"참여자 0/4명에게 SMS 발송 완료"** 라고 떴다.
신랑신부는 하객 4명이 문자를 받은 줄 알고 넘어갔다. 지금은:

| 결과 | 화면 |
|---|---|
| 전원 실패 | 🔴 "전원 실패했습니다. 하객은 아직 아무 연락도 못 받았습니다. 사유: …" |
| 일부 실패 | 🔴 "n명에게만 갔습니다. 나머지 m명은 못 받았습니다. 사유: …" |
| 전부 성공 | 🟢 "n명에게 SMS 발송 완료" |
| 대상 없음·키 미설정 | 🟢 의도된 미발송 (실패 아님) |

판정은 `src/lib/smsResult.ts` 한 곳에만 있다. **한 건이라도 실패하면 초록
알림이 아니라 빨간 오류다.** 솔라피가 준 사유를 그대로 보여주되, 오류 본문에
섞여 오는 수신번호는 지운다(스크린샷·버그 리포트로 새면 안 되므로).

이 화면이 없었으면 위의 두 원인(키 공백 → IP 제한)을 못 찾았다. 실패를
성공처럼 말하는 화면은 그 자체가 장애다.

## 막혔을 때 보는 순서

1. 어드민 화면의 **빨간 오류에 찍힌 사유**를 먼저 읽는다. 대개 여기서 끝난다
2. `Forbidden … 허용되지 않은 IP` → 솔라피 IP 제한을 끈다 (위 참고)
3. `apiKey length must be 16` → 환경변수 재입력. 오류에 찍힌 글자 수와
   솔라피 콘솔의 API Key 를 대조한다
4. 발신번호 미등록·잔액 부족도 4xx 로 온다 — 솔라피 콘솔에서 확인
