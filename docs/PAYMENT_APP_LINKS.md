# 축의금 계좌이체 안내

- 신랑·신부 각 계좌의 `kakaoPayUrl`에 실제 수취인의 카카오페이 송금 링크가 설정된 경우에만 “카카오페이 송금하기” 버튼을 표시한다. 계좌번호로 송금 링크를 만들지 않는다.
- 카카오페이 버튼을 누르면 해당 수취인의 송금 링크를 열고, 송금은 카카오페이에서 진행한다. 카카오페이 머니로 받는 방식임을 버튼 아래에 안내한다.
- 카카오뱅크 계좌번호와 복사 버튼을 함께 표시한다. 복사 값은 계좌번호만이며, 이용자가 평소 사용하는 은행 앱에서 이체하도록 안내한다.
- 복사 실패 시 계좌번호를 직접 입력하도록 안내한다. 토스 버튼이나 앱 설치 안내, 외부 앱 자동 이동은 없다.
- 기존 NEXT_PUBLIC_KAKAO_PAY_URL / NEXT_PUBLIC_TOSS_PAY_URL 환경변수는 사용하지 않는다.
